# Gable for Cursor and Grok Bot

Connects Gable (https://getgable.ca) to Cursor and Grok Bot through Gable's
remote MCP server at `https://getgable.ca/api/mcp`. You sign in with your
Gable account; nothing is stored in this plugin.

What it can do: look up and update listings and buyers, log showings and
feedback, record offers and conditions, complete tasks and read
notifications.
